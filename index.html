What changed in v0.2

NIST JANAF query

The example no longer reveals the two graded values. The verifier now checks which compound was returned and whether the units are correct, as well as the numbers.

Synthesis precursor recommendation

At least five distinct routes must match the specified Materials Project corpus. Chemical plausibility alone no longer counts; unmatched extras do not invalidate five matches. One misattributed corpus entry was removed, not the task.

Electrochemical stability window

The new reference uses the supplied target and a fixed set of 95 competing phases, instead of substituting the lowest-energy structure with the same formula. The verifier now also checks hull distance, target energy and phase count.

Across the suite

The 31 tasks now deny outbound network access by default, with specific scientific data hosts allowed where needed. Verifiers run offline. Trials with recorded exceptions or missing verifier rewards are excluded from current scores rather than counted as model failures.
